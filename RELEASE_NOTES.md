# ShioDiary 0.1.0

First public Windows x64 distribution.

- Local-first diary storage with Markdown editing, DOCX/TXT import/export, images, and audio.
- Automatic saves and recovery drafts, timeline navigation, search, tags, and favorites.
- Three themes and optional local background customization.
- Optional user-triggered GitHub Push/Pull.
- Windows account verification on app startup.
